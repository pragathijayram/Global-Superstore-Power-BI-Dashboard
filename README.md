# 📊 Global Superstore - End-to-End Power BI Dashboard

An interactive multi-page business intelligence dashboard built using Microsoft Power BI to analyze global retail sales, regional performance, and time-based trends based on the "Sample - Superstore" dataset.

---

## 🚀 Key Dashboard Pages & Features

1. **Executive Overview (Page 1):**
   - High-level KPIs including **Total Sales** and **Total Profit**.
   - Interactive **Category Slicer** to dynamically filter overall business metrics.

2. **Regional Analysis (Page 2):**
   - Detailed **Region and Segment Analysis** using clustered bar charts.
   - Dedicated metrics tracking performance for high-value regions (e.g., **West Region Sales**).

3. **Time Trends (Page 3):**
   - Advanced Time-Intelligence DAX measure for **Year-to-Date (YTD) Sales** (`TOTALYTD`).
   - Monthly trend line analysis tracking sales fluctuations over time.

---

## 🛠️ Technical Skills & Tools Used
- **Tool:** Power BI Desktop, DAX Studio.
- **DAX Functions:** `SUM`, `CALCULATE`, `TOTALYTD`, `SUMX`.
- **Data Modeling & Visualization:** Multi-page layout navigation, Card visuals, Matrix/Tables, Slicers, and Line/Bar Charts.
